Backup key (if this PC is lost)

ALFRED's backups are encrypted with a backup key that stays on this PC. So a new PC can open them, ALFRED locks a copy of the key with a passphrase you choose and keeps only that locked copy in your Cloudflare R2 bucket or in a hidden ALFRED folder in your Google Drive. On a new PC: fetch the copy and type the passphrase. Neither Cloudflare nor Google can open it without your passphrase, and ALFRED never stores or sends the passphrase. If you forget it, the backups cannot be opened.

Nightly backup to Cloudflare R2

In Cloudflare: R2 Object Storage, create a bucket, then Manage API tokens, Create Account API token, Object Read & Write for that bucket only. ALFRED checks the values with Cloudflare before saving them in this PC's private config, and never shows the secret again. Google Drive uses the Google sign-in set up for ALFRED. In your Google Cloud project, turn on the Google Drive API and add the "app data" Drive permission (drive.appdata) to the consent screen; ALFRED can then see only its own file, never your other Drive files. Once the key and its locked copy are saved, ALFRED backs everything up to your R2 bucket each night, encrypted, and keeps the newest 7, or fewer so the bucket stays inside Cloudflare's free 10 GB.
