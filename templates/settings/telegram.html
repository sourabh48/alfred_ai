Ask ALFRED from Telegram about your next trip, due career follow-ups, Home notices or any public question.

Telegram's servers see these messages, so money, documents and saved history never go there. ALFRED only replies; it never books, sends, pays or changes anything.

How to set up the bot
  1. In Telegram, message @BotFather and send /newbot.
  2. Choose a name, then a username ending in "bot".
  3. Add the token it gives you to config/local.env in ALFRED's data folder as ALFRED_TELEGRAM_BOT_TOKEN=…
  4. Restart ALFRED, then come back here for a link code. Never paste the token into a chat.
