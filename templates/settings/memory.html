Private Memory

Verified memories stay on this computer. Connected family members cannot read them. Deleting a memory also revokes journal recovery of it.

Retention runs whenever memories are accessed and at local startup. Old recovery backups retain their original data and must be retired separately.

Check Memory Retrieval

Test a question against a memory you have verified, or choose that no memory should match. Results measure retrieval, not whether an answer is true. Questions and results are not saved.
