Install in four steps

These illustrations show the steps to follow. Windows and setup screens can look different on your PC.

01 · Download

Choose your Windows package

Download ALFRED-Setup.exe for normal installation. You do not need a separate Python, pip, Docker, PostgreSQL or Redis installation.

Prefer portable? Download the ZIP and extract the entire folder before running it.

02 · Install

Follow the setup wizard

Open the downloaded installer, follow setup, then finish. Installation is for your Windows account and does not require administrator access.

ALFRED creates desktop and Start menu shortcuts, including a named uninstaller.

03 · Launch

Open your workspace

Open ALFRED from the desktop or Start menu. Wait for the progress window to finish and your browser to open, then create an account or sign in.

For the portable ZIP, open ALFRED Launcher.exe in the extracted ALFRED folder.

04 · Find the tray icon

ALFRED stays within reach

Look for the A icon near the Windows clock. It remains while ALFRED runs, including after you close the browser. Click it to open the app; right-click for the menu.

If it is hidden, use the ↑ arrow in the notification area. You can move it into the visible tray using Windows taskbar settings.

Your accounts and files stay separate from the program.
Installer and portable copies use %LOCALAPPDATA%\ALFRED by default. They do not import a development checkout's accounts automatically. Uninstalling preserves this data folder.

A few useful details

How do I update or uninstall?

Back up your data, then run the newer installer. For portable use, stop ALFRED before replacing its extracted program folder. Uninstall using the Start menu, Windows Settings → Apps, or Uninstall ALFRED.cmd in the installed program folder. Saved data is retained.

Where is the browser address?

The usual address is http://127.0.0.1:8000/. ALFRED selects another port when necessary. Use the launcher or tray icon to open the right address.

What should I back up?

Keep the database, uploads, models and private configuration together. Follow the backup and restore guide. Do not publish your data folder or local credentials.

Does everything work offline?

The interface, local data and OCR assets are bundled. Live external sources and configured integrations need internet access. Background schedules run while the PC and ALFRED are on.

Developers: run from source

Use this separate route to change code or run tests. The packaged app above needs none of these setup steps.

Install Git and Python 3.12, then run in PowerShell:

git clone https://github.com/sourabh48/alfred_ai.git
cd alfred_ai
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe alfred_native.py start

Source runs use the checkout as the default data folder. Keep runtime secrets in untracked local environment files. See the development guide for tests and builds.
