# ALFRED 1.0.0 — Windows preview

ALFRED brings personal finances, document review and related planning into a
local Windows workspace. This preview packages the Windows build verified on
26–27 September 2026. It includes its own Python runtime and dependencies.

## Downloads

- **ALFRED-Setup.exe** — recommended for desktop/Start menu shortcuts and a named uninstaller.
- **ALFRED-Windows-x64.zip** — extract the entire ZIP and open `ALFRED Launcher.exe`.
- **SHA256SUMS.txt** — SHA-256 hashes for the installer and portable ZIP.
- **release-manifest.json** — package components, sizes and checksums.
- **READ ME.txt** — standalone installation and operation instructions.

Use a Windows x64 PC and a browser. A separate Python, pip, Docker, PostgreSQL
or Redis installation is not required. The installer runs for the current
Windows user without administrator access.

## First launch and data

1. Run the installer, or extract the portable ZIP completely.
2. Open ALFRED and wait for the launcher to open your browser.
3. Create an account or sign in to an account in the selected data folder.

Installed and portable copies default to `%LOCALAPPDATA%\ALFRED`. They do not
automatically import a development checkout's accounts or uploads. Updating or
uninstalling preserves that separate data folder. Back up the database, uploads,
models and private configuration together before moving data.

Closing the browser does not stop background work. Use **Stop ALFRED** in the
Start menu or **Stop ALFRED.cmd** in the portable folder. Uninstall through the
Start menu, Windows Settings > Apps, or **Uninstall ALFRED.cmd**.

## Preview limits

Clean second-PC installation/reboot, a completed continuous scheduled-work
observation, human screen-reader checks and broader real-data accuracy remain
open. Training a model does not establish prediction accuracy. Live external
sources require internet access; optional LAN and live-account integrations
need their own configuration and validation.

The release excludes the developer's database, uploads, model data and local
credentials. Runtime hosting remains local or LAN-only.

See the repository's README for separate user and developer setup instructions,
and `docs/WINDOWS_PACKAGE_VERIFICATION_20260927.md` for the detailed verification record.
