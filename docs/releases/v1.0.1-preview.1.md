# ALFRED 1.0.1 — tray controls and illustrated setup

ALFRED now remains visible in the Windows notification area while its local
server runs. This update also refreshes the desktop launcher and includes an
illustrated installation guide that opens offline.

## What changed

- **Persistent ALFRED tray icon:** click to open the correct local browser
  address. Right-click for the installation guide, data folder or graceful stop.
  The icon remains while background jobs finish, then disappears after shutdown.
- **Clearer launcher:** matching ALFRED branding, readable startup/shutdown
  messages, a progress indicator and a reminder about the tray icon.
- **Illustrated instructions:** four pictures cover download, installation,
  first launch and tray controls. The guide adapts to desktop and narrow screens,
  with separate developer setup instructions.

Windows can put the icon under the notification area's arrow. It also appears
when ALFRED starts quietly after Windows sign-in.

## Download and install

Use **ALFRED-Setup.exe** for a normal per-user installation. No administrator
access or separate Python, pip, Docker, PostgreSQL or Redis setup is required.
For portable use, extract the complete ZIP and open **ALFRED Launcher.exe**.

This preview installer is unsigned. Compare downloaded files with
**SHA256SUMS.txt** from this release. **release-manifest.json** records package
contents and hashes; **READ.ME.txt** contains standalone operating instructions.

The default data folder is `%LOCALAPPDATA%\ALFRED`, separate from program files.
Back up your data before updating. Installing this release does not import an
existing source checkout's accounts automatically. Updating or uninstalling
retains the saved accounts, uploads, settings and models.
